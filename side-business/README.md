# 副業事業計画：通信インフラ専門知識 × AI増幅型サービス

**前提条件**
- 本人：携帯電話設備の保守運用の専門職（非エンジニア枠での副業）
- 稼働時間：週5時間以内
- 体制：指示役 = 上位モデル（Claude）／実行役 = Sonnet・Haiku（タスクにより切替）／コード = Codex
- 人間の役割：受注のやり取り・専門的な監修（最終品質チェック）・納品のみ

---

## 1. 事業コンセプト

一般のライターやコンサルには書けない「通信インフラの現場実務知識」を商品化する。
制作物の下書き・構成・量産はすべてAI実行役が行い、**あなたは希少性の源泉（実務経験に基づく監修）だけを提供する**。

週5時間の内訳目安：

| 作業 | 時間/週 |
|---|---|
| 受注・顧客とのメッセージ対応 | 1.5h |
| AIが作った成果物の専門監修・修正指示 | 2.5h |
| 納品・請求・振り返り | 1.0h |

## 2. 収益目標（現実的なフェーズ設定）

「週5時間で即・本業並み」は現実的ではないため、段階を踏む。
時間単価を上げる（受託）＋積み上がる資産を作る（教材・テンプレート）の二本立てで、
後者が育つほど稼働時間を増やさずに収益が伸びる構造にする。

| フェーズ | 期間 | 月間目標 | 主な収益源 |
|---|---|---|---|
| 1. 実績づくり | 〜3ヶ月 | 3〜5万円 | ココナラ/クラウドワークスでの記事監修・文書作成 |
| 2. 単価向上 | 4〜6ヶ月 | 8〜15万円 | 監修者契約（継続）、資格教材の販売開始 |
| 3. 資産化 | 7〜12ヶ月 | 15〜30万円 | 教材・テンプレートのストック収益＋高単価監修 |
| 4. 本業並み | 12ヶ月〜 | 30万円〜 | ストック収益が過半。稼働時間は据え置き |

## 3. 90日ロードマップ

**Week 1-2：開店準備**
- ココナラ・クラウドワークスのアカウント開設、プロフィール整備（→ `sales-templates.md`）
- サービス3種を出品（→ `service-menu.md`）
- 実績用サンプル成果物をAI実行役で3点制作、本人が監修

**Week 3-6：初受注**
- クラウドワークスの「通信」「5G」「監修」案件に週3件提案（提案文はテンプレ化済み）
- 低単価でも監修実績を3件獲得し、評価を貯める

**Week 7-12：単価を上げる**
- 実績を根拠に単価を1.5〜2倍に改定
- 通信系Webメディアへ「監修者」として直接営業（月1〜2社）
- 資格教材（一陸特など）の第1弾をAI実行役と制作開始

## 4. ファイル構成

| ファイル | 内容 |
|---|---|
| `service-menu.md` | サービスメニューと価格表 |
| `sales-templates.md` | プロフィール文・出品文・提案文のテンプレート |
| `operations.md` | 指示役/実行役の分担とモデル切替ルール、週次の回し方 |
| `prompts.md` | 実行役（Sonnet/Haiku）と Codex に渡すプロンプト・仕様書テンプレート |

## 5. 必ず守ること（コンプライアンス）

1. **勤務先の副業規定を先に確認する。** 通信キャリア・保守会社は副業許可制のことが多い。
2. **守秘義務。** 勤務先固有の手順書・障害情報・顧客情報・ネットワーク構成は一切使わない。商品化するのは「業界一般の知識と経験」のみ。
3. **競業避止。** 勤務先の顧客・競合から直接受注しない。
4. **年間所得20万円超で確定申告**が必要（住民税は金額によらず申告）。
5. AI生成物は必ず本人が監修してから納品する。無監修の納品は品質事故と信用毀損のもと。
