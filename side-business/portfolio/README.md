# 制作実績（ポートフォリオ）

Googleスプレッドシート＋GASによる業務自動化ツールのデモ3点。
いずれも外部サービス通信なし・カスタムメニューだけで操作可能・使い方マニュアル付き。

| # | ツール | 業務領域 | 主な機能 |
|---|---|---|---|
| 01 | [見積書・請求書・納品書 自動発行](./01-invoice-generator/) | 経理・営業事務 | 帳票PDFの自動生成・自動採番・消費税計算（10%/軽減8%）・月次売上集計 |
| 02 | [勤怠管理・自動集計](./02-attendance-tracker/) | 労務・総務 | 実働/残業/深夜時間の自動計算（日またぎ夜勤対応）・残業アラート・パート概算支給額 |
| 03 | [顧客・案件進捗管理](./03-case-manager/) | 営業事務・士業 | 期限超過/間近の自動色分け・担当者別ダッシュボード・毎朝の自動チェック（トリガー） |

## 各フォルダの内容

- `code.gs` … GAS本体（日本語コメント付き、コピペで導入可能）
- `README.md` … 非エンジニア向けのセットアップ＋使い方マニュアル
- `sample_*.csv` … 動作確認用の架空データ（意図的な異常データ入り。エラー処理のデモに使用）

## 共通の品質基準

1. 入力ミスがあっても処理を止めず、「エラー一覧」シートに原因と対処ヒントを記録して続行
2. 0件データ・空行・境界値でエラー落ちしない
3. 初期セットアップは何度実行しても既存データを壊さない（冪等）
4. 外部API・外部サービスへの通信なし（顧客データがスプレッドシートの外に出ない）
