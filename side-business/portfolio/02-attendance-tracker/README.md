# 勤怠管理・自動集計ツール

タイムカード（打刻記録）を Google スプレッドシートに入力するだけで、
毎月の実働時間・残業時間・深夜時間を自動集計し、残業超過者にアラートを
表示するツールです。エンジニアでなくても、メニューをクリックするだけで
使えるように作られています。

対象読者：総務・経理担当の方（プログラミングの知識は不要です）

---

## 1. このツールでできること

- 「打刻記録」シートに出勤・退勤時刻を入力するだけで、社員ごとの
  **実働時間・残業時間・深夜時間** を自動計算します。
- **深夜0時をまたぐ勤務（例：22:00出勤→翌7:00退勤）** も正しく計算します。
- 残業が多い社員の行を自動的に色付けし、超過時間を表示します（残業アラート）。
- 入力ミス（社員IDの間違い、時刻の入れ忘れなど）があっても集計処理は止まらず、
  問題のある行だけを「エラー一覧」シートにまとめて記録します。
- すべての操作はスプレッドシート上部のメニュー「勤怠管理ツール」から行います。
- 外部のサービスやAPIとは通信しません。データはすべてこのスプレッドシートの
  中だけで完結します。

---

## 2. 初回設定

最初の1回だけ行う設定です。担当者が変わっても、この手順書だけで再現できます。

### 手順1：スプレッドシートを新規作成する

Google ドライブで新しい Google スプレッドシートを作成し、分かりやすい名前
（例：「勤怠管理_2026年度」）を付けます。

【画面：Googleドライブで「新規」→「Googleスプレッドシート」を選択している状態】

### 手順2：スクリプトエディタを開く

スプレッドシート上部メニューから「拡張機能」→「Apps Script」を選択します。

【画面：スプレッドシートの「拡張機能」メニューを開き「Apps Script」が見えている状態】

### 手順3：サンプルコードを削除する

Apps Script エディタが開いたら、最初から入っている `function myFunction() {}`
などのコードをすべて選択し、削除します。

【画面：Apps Scriptエディタでコードが全選択されている状態】

### 手順4：`code.gs` の中身を貼り付ける

このフォルダにある `code.gs` の内容をすべてコピーし、手順3で空にした
エディタに貼り付けます。

【画面：Apps Scriptエディタに勤怠管理ツールのコードが貼り付けられた状態】

### 手順5：保存する

画面左上のフロッピーディスクのアイコン（保存）をクリックします。
プロジェクト名を聞かれたら「勤怠管理ツール」など分かりやすい名前を入力します。

【画面：Apps Scriptエディタの保存アイコンとプロジェクト名入力ダイアログ】

### 手順6：スプレッドシートに戻り再読み込みする

スプレッドシートのタブに戻り、ブラウザの再読み込み（F5キーなど）を行います。
数秒後、メニューバーに「勤怠管理ツール」という項目が追加されます。

【画面：スプレッドシート上部メニューに「勤怠管理ツール」が表示された状態】

> 表示されない場合は、もう一度ブラウザの再読み込みをしてください。

### 手順7：「① 初期セットアップ」を実行する

「勤怠管理ツール」メニュー→「① 初期セットアップ」をクリックします。

【画面：「勤怠管理ツール」メニューを開き「① 初期セットアップ」が見えている状態】

### 手順8：権限の承認を行う（初回のみ）

初めて実行すると「承認が必要です」という画面が出ます。これは、このスクリプト
がこのスプレッドシート自体を編集するために必要な、Google 標準の確認画面です。
「権限を確認」→ 自分のGoogleアカウントを選択 →「詳細」→
「（プロジェクト名）に移動（安全ではないページ）」→「許可」の順に進めてください。

【画面：Googleの「このアプリはGoogleで確認されていません」承認確認画面】

> ここで表示される警告は、個人や社内で作成した独自のスクリプトを実行する際に
> 必ず表示されるものです。このツールは外部と通信しないため、内容に問題は
> ありません。

### 手順9：セットアップ完了を確認する

「初期セットアップ完了」というメッセージが表示され、以下の5つのシートが
自動的に作成されます。

| シート名 | 内容 |
|---|---|
| 従業員マスタ | 社員ID・氏名・雇用形態・時給・所定労働時間を登録する |
| 打刻記録 | 毎日の出勤・退勤時刻を入力する |
| 月次集計 | 自動計算された結果が出力される（手入力不要） |
| 設定 | 残業アラート閾値・深夜時間帯・集計対象年月を設定する |
| エラー一覧 | 入力ミスがあった行が自動的に記録される |

【画面：5つのシートタブが並び、「初期セットアップ完了」のダイアログが表示された状態】

「従業員マスタ」と「打刻記録」には、動作確認用のサンプルデータが自動で
入っています。本番運用の前に、このサンプル行は削除するか、実際のデータで
上書きしてください（日またぎ勤務やエラーの例として、あえて残しておき
一度「② 月次集計の実行」を試してみることをおすすめします）。

### 手順10：従業員マスタを登録する

「従業員マスタ」シートに、自社の社員を1人1行で入力します。

- 社員ID：他の社員と重複しない任意のID（例：E001）
- 氏名
- 雇用形態：「正社員」または「パート」をプルダウンから選択
- 時給（パートのみ）：パートの場合のみ入力。正社員は空欄でよい
- 所定労働時間(h/日)：1日あたりの所定労働時間（例：8）

【画面：従業員マスタシートに複数名の社員データが入力された状態】

### 手順11：設定シートを確認する

「設定」シートを開き、以下を確認・変更します。

- 残業アラート閾値(h/月)：この時間を超えたら警告表示（例：45）
- 深夜開始時刻／深夜終了時刻：通常は変更不要（既定 22:00〜5:00）
- 集計対象年月：集計したい年月を「2026-07」の形式で入力

【画面：設定シートの4項目が入力された状態】

初回設定はここまでです。以降は「3. 毎回の操作」を毎月繰り返します。

## 3. 毎回の操作（月次の運用）

### 手順1：打刻記録を入力する

「打刻記録」シートに、日々の勤怠を1日1行で入力します。

- 日付：その日の日付
- 社員ID：従業員マスタに登録済みのID
- 出勤時刻：「9:00」のように入力（自動で時刻として認識されます）
- 退勤時刻：同上
- 休憩時間(分)：休憩の合計分数（例：60）。無給休憩がなければ空欄でも可

【画面：打刻記録シートに1ヶ月分のデータが入力された状態】

> 日をまたぐ勤務（例：22:00出勤→翌7:00退勤）は、日付欄には
> **出勤した日の日付** を入力してください。翌日への繰り越しはツールが
> 自動で判定します。

### 手順2：集計対象年月を確認する

「設定」シートの「集計対象年月」が、これから集計したい月になっているか
確認します（月が変わったら更新してください）。

【画面：設定シートの集計対象年月セルにその月の値が入っている状態】

### 手順3：「② 月次集計の実行」をクリックする

「勤怠管理ツール」メニュー→「② 月次集計の実行」をクリックします。

【画面：メニューから「② 月次集計の実行」を選択している状態】

数秒で完了メッセージが表示され、「月次集計」シートに社員ごとの
出勤日数・実働時間・残業時間・深夜時間・（パートは）概算支給額が
自動で出力されます。エラーがあった場合は件数が表示されるので、
「エラー一覧」シートで内容を確認してください。

【画面：月次集計シートに計算結果が並んでいる状態】

### 手順4：「③ 残業アラートチェック」をクリックする

「勤怠管理ツール」メニュー→「③ 残業アラートチェック」をクリックします。

【画面：メニューから「③ 残業アラートチェック」を選択している状態】

「設定」シートの残業アラート閾値を超えた社員の行が赤系の色で強調表示され、
「アラート」列に超過時間が表示されます。

【画面：月次集計シートで一部の行が赤くハイライトされ「⚠ 閾値超過」と表示された状態】

### 手順5：エラー一覧を確認する（エラーが出た場合のみ）

「② 月次集計の実行」でエラー件数が表示された場合は、「エラー一覧」シートを
開き、内容を確認します。原因が分かる行があれば「打刻記録」または
「従業員マスタ」を修正し、もう一度「② 月次集計の実行」を行ってください。

【画面：エラー一覧シートに複数のエラー行が記録された状態】

以上で毎月の作業は完了です。

## 4. 集計のルール（残業・深夜・日またぎの考え方）

計算方法を知らなくても使えるツールですが、社員から質問があったときのために
考え方をまとめます。

### 実働時間

```
実働時間 = （退勤時刻 − 出勤時刻） − 休憩時間
```

### 残業時間

```
その日の残業時間 = 実働時間 − 所定労働時間（マイナスの場合は0）
```

「月次集計」の残業時間は、この **日ごとの超過分を1ヶ月分合計した値** です。
（ある日多く働いた分を、別の日が短かった分で相殺することはしていません。）

### 深夜時間

「設定」シートで指定した時間帯（既定：**22:00〜翌5:00**）に勤務していた
時間を、深夜時間として計算します。日をまたぐ勤務でも、日ごとに深夜帯との
重なりを計算して合計するため、正しく算出されます。

例：22:00出勤→翌7:00退勤（休憩60分）の場合
- 実働時間：8時間（9時間 − 休憩1時間）
- 深夜時間：7時間（22:00〜翌5:00の7時間がすべて勤務時間に含まれるため）

> ※ 簡易計算のため、休憩時間がちょうど深夜帯の中にあった場合でも、
> 深夜時間から休憩分を厳密には差し引いていません（深夜時間が実働時間を
> 超えないようには調整しています）。より厳密な計算が必要な場合は、
> 休憩時間を深夜帯以外の時間に取るよう運用でカバーしてください。

### 日またぎ勤務の扱い

出勤時刻より退勤時刻の方が早い（例：出勤22:00、退勤7:00）場合、
ツールは自動的に「退勤は翌日である」と判断して計算します。

ただし、これは「時刻の入力ミス」との区別が難しいため、日をまたいだと
解釈しても勤務時間が **20時間を超える場合はエラー** として扱い、
「エラー一覧」シートに記録します（例：出勤9:00・退勤8:30のような、
単純な入力ミスを日またぎ勤務と誤って計算してしまうことを防ぐためです）。

### 概算支給額（パートのみ）

```
概算支給額 = 時給 × 実働時間
```

残業手当・深夜割増などの割増分は含まない、簡易的な目安の金額です。
給与計算や賃金台帳としてそのまま使用しないでください。

## 5. 困ったとき（想定エラーと対処）

「② 月次集計の実行」を行うと、入力ミスのある行は処理を止めずに
「エラー一覧」シートへ記録されます。よくある3つのエラーと対処方法です。

### エラー1：「社員IDが従業員マスタに存在しません」

**原因**：「打刻記録」に入力した社員IDが、「従業員マスタ」に登録されていない
（社員IDの入力ミス、または従業員マスタへの登録漏れ）。

**対処**：
1. 「エラー一覧」シートで該当行の社員IDを確認する。
2. 「従業員マスタ」にその社員が登録されているか確認する。登録漏れなら追加する。
3. 「打刻記録」側の社員IDが誤字・全角半角違いなどになっていないか確認し、修正する。
4. 修正後、「② 月次集計の実行」をもう一度行う。

### エラー2：「出勤時刻が空です」／「退勤時刻の形式が不正です」

**原因**：出勤・退勤時刻の入力漏れ、または「9時」「午前9時」のような
ツールが認識できない形式で入力されている。

**対処**：
1. 「エラー一覧」シートで該当行の日付・社員IDを確認する。
2. 「打刻記録」シートの該当セルを、「9:00」のような「時:分」の形式で
   入力し直す。
3. 修正後、「② 月次集計の実行」をもう一度行う。

### エラー3：「退勤時刻が出勤時刻より前で…不正な時刻データと判断しました」

**原因**：退勤時刻が出勤時刻より前になっており、日またぎ勤務として
計算しても20時間を超えてしまう（多くの場合、時刻の入力ミス）。

**対処**：
1. 「エラー一覧」シートで該当行の日付・社員IDを確認する。
2. 「打刻記録」シートで実際の出勤・退勤時刻を確認し、正しい時刻に修正する。
3. 本当に日をまたぐ長時間勤務（20時間超）だった場合は、出勤日と退勤日を
   2行に分けて入力するなど、運用ルールを決めて対応する。
4. 修正後、「② 月次集計の実行」をもう一度行う。

---

### その他：メニューが表示されない／実行してもエラーになる

- ブラウザを再読み込み（F5キー）してから、もう一度確認してください。
- それでも「勤怠管理ツール」メニューが出ない場合は、Apps Script エディタに
  `code.gs` の内容がすべて貼り付けられているか、保存されているか確認して
  ください（本ドキュメントの「2. 初回設定」手順4〜5）。
- メニューを実行して赤いエラーメッセージが出た場合は、いったん
  「① 初期セットアップ」を実行し直してから、もう一度お試しください。
