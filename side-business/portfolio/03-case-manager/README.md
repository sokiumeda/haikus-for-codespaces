# 顧客・案件進捗管理ツール

Googleスプレッドシート + Google Apps Script（GAS）で動く、案件の期限・進捗管理ツールです。
税理士・社労士等の士業事務所や、中小企業の営業事務担当者の方が、
「担当している案件の期限をうっかり見落とす」「誰が何件抱えているか分からない」
といった抜け漏れを防ぐために使います。

エンジニアでなくても、画面上部のメニューから操作するだけで使えます。
コードを書いたり読んだりする必要はありません。

---

## このツールでできること

1. **顧客情報と案件情報を表形式で一元管理**（顧客マスタ／案件一覧の2枚のシート）
2. **期限チェックをワンクリックで実行**し、案件一覧の行を自動で色分け
   - 赤色：期限を過ぎている案件（要対応）
   - 黄色：期限が近づいている案件（既定は7日以内、変更可）
   - 色なし：まだ余裕がある案件、または完了した案件
3. **ダッシュボードをワンクリックで自動生成**
   - ステータス別（着手前／対応中／確認待ち／完了）の件数
   - 担当者別の対応中件数・完了件数・進捗率
   - 期限超過案件・期限間近案件の一覧
4. **入力ミスがあっても処理が止まらない**
   - 顧客マスタに存在しない顧客ID、日付になっていない期限日、
     決められた4種類以外のステータスなどを入力していても、
     その行だけ「エラー一覧」シートに記録され、他の行の処理は続行されます

## 初回設定

### 手順1：スプレッドシートを新規作成する

1. Googleドライブで新しいGoogleスプレッドシートを作成する
   【画面：Googleドライブの「新規」メニューを開いた状態】
2. 分かりやすいファイル名に変更する（例：「案件管理_〇〇事務所」）

### 手順2：スクリプトを貼り付ける

1. スプレッドシート上部メニューの「拡張機能」→「Apps Script」を開く
   【画面：拡張機能メニューを開き「Apps Script」が見えている状態】
2. エディタに最初から入っている `myFunction() {}` などのサンプルコードを全選択して削除する
3. このツールに同梱されている `code.gs` の中身を全部コピーし、エディタに貼り付ける
   【画面：Apps Scriptエディタにコードを貼り付けた直後の状態】
4. 画面左上のプロジェクト名（「無題のプロジェクト」など）をクリックし、
   分かりやすい名前に変更する（例：「案件管理ツール」）
5. 画面上部のフロッピーディスクのアイコン（保存）をクリックする
   【画面：保存アイコンをクリックした直後、変更が保存された状態】

### 手順3：スプレッドシートに戻って再読み込みする

1. スプレッドシートのタブに戻る
2. ブラウザの再読み込み（F5キーまたは更新ボタン）を行う
3. 数秒待つと、メニューバーに「案件管理ツール」という新しいメニューが表示される
   【画面：メニューバーに「案件管理ツール」が追加された状態】

### 手順4：初期セットアップを実行する

1. 「案件管理ツール」メニュー →「① 初期セットアップ」をクリックする
   【画面：「① 初期セットアップ」をクリックする直前のメニュー展開状態】
2. 初回のみ「承認が必要です」という画面が出るので、「権限を確認」をクリックする
   【画面：Googleの権限確認ダイアログが表示された状態】
3. 自分のGoogleアカウントを選択する
4. 「このアプリは Google で確認されていません」という警告が出た場合、
   「詳細」→「（プロジェクト名）に移動」の順にクリックする
   【画面：未確認アプリの警告画面】
5. 「許可」をクリックする
   （このスクリプトは外部の通信は一切行わず、あなた自身が作成したスプレッドシートの
   中だけで動作します。安全に許可して問題ありません）
6. 「初期セットアップが完了しました」というメッセージが表示されたら完了
   【画面：セットアップ完了のアラートダイアログ】
7. シート下部のタブに「顧客マスタ」「案件一覧」「ダッシュボード」「設定」「エラー一覧」の
   5枚のシートが自動で作られていることを確認する
   【画面：シートタブが5枚並んでいる状態】

### 手順5：記入例を確認し、自社のデータに置き換える

1. 「顧客マスタ」シートを開くと、1行目が見出し、2行目に
   「（記入例）サンプル商事株式会社」という仮のデータが入っている
   【画面：顧客マスタの記入例が入った状態】
2. 記入例の行を実際の顧客データで上書きするか、削除して自社のデータを追加する
3. 「案件一覧」シートも同様に、記入例（J001）を確認しながら実際の案件を入力していく
   - 「顧客ID」欄には、必ず「顧客マスタ」に登録済みのIDを入力する
   - 「期限日」欄は必ず日付として入力する（セルを日付形式にしてから入力すると確実）
   - 「ステータス」欄はプルダウンから選ぶ（着手前／対応中／確認待ち／完了）

### 手順6（任意）：期限間近と見なす日数を変更する

1. 「設定」シートを開く
2. 「期限間近日数」の行のB列（値）に、任意の日数を入力する（初期値は7）
   【画面：設定シートで期限間近日数を編集している状態】

## 毎回の操作

日々の運用では、次の2つを実行するだけです。

### 操作1：期限チェック実行（案件を追加・更新したとき）

1. 「案件管理ツール」メニュー →「② 期限チェック実行」をクリックする
2. 「案件一覧」シートの行が自動で赤・黄・色なしに塗り分けられる
   【画面：案件一覧の行が赤・黄色に色分けされた状態】
3. 完了メッセージが表示される。エラーがあった場合は件数が表示されるので、
   「エラー一覧」シートを確認する
   【画面：期限チェック完了のアラートダイアログ（エラーあり）】

### 操作2：ダッシュボード更新（現状を把握したいとき／朝一番など）

1. 「案件管理ツール」メニュー →「③ ダッシュボード更新」をクリックする
2. 「ダッシュボード」シートに、ステータス別件数・担当者別状況・
   期限超過リスト・期限間近リストがまとめて表示される
   【画面：ダッシュボードに集計結果が表示された状態】

以上の2つは何度クリックしても安全です（最新の内容に上書きされるだけで、
「顧客マスタ」「案件一覧」の入力データが消えることはありません）。

## 困ったとき（想定エラーと対処）

### エラー1：「顧客マスタに存在しない顧客IDです」と出る

**原因**：「案件一覧」に入力した顧客IDが、「顧客マスタ」に登録されていない
（IDの誤入力・入力漏れ・全角半角の違いなど）。

**対処**：
1. 「エラー一覧」シートを開き、該当する行番号と入力値を確認する
2. 「案件一覧」の該当行に戻り、顧客IDを「顧客マスタ」に登録済みの正しいIDに修正する
3. 「② 期限チェック実行」を再度クリックし、エラーが解消されたか確認する

### エラー2：「期限日が日付形式ではないか、空欄です」と出る

**原因**：「期限日」欄が空欄になっている、または文字列として日付を入力してしまっている
（例：セルの書式が「文字列」になっている状態で「令和8年1月1日」のように手入力した等）。

**対処**：
1. 「案件一覧」の該当セルを選択し、右クリック→「表示形式」→「日付」に変更する
2. 日付を入力し直す（カレンダーから選択するか、`2026/01/01` のように半角スラッシュ区切りで入力する）
3. 再度「② 期限チェック実行」を実行して確認する

### エラー3：「不正なステータス値です」と出る

**原因**：ステータス欄に「着手前」「対応中」「確認待ち」「完了」以外の文字
（スペースの入り方の違い、独自の表現、コピー時の誤入力など）が入っている。

**対処**：
1. 「案件一覧」の該当セルをクリックし、プルダウンから正しいステータスを選び直す
2. プルダウンが表示されない場合は、そのセルを一度削除してから
   隣接する正しいセルをコピー＆値の貼り付け（プルダウンごと）するか、
   「① 初期セットアップ」を一度実行し直すとプルダウンが復旧する
3. 再度「② 期限チェック実行」を実行して確認する

### その他

- **メニューが表示されない**：ブラウザの再読み込みを行ってください。それでも出ない場合は、
  「拡張機能」→「Apps Script」を開き、関数選択で `onOpen` を選んで手動実行してみてください。
- **「エラー一覧」に何も出ないのにおかしい気がする**：
  「② 期限チェック実行」または「③ ダッシュボード更新」を実行するたびに
  「エラー一覧」の内容は最新の結果に上書きされます。過去のエラーを残したい場合は、
  別シートにコピーしてから保管してください。
- **色が消えない／色が正しくない**：「② 期限チェック実行」を再実行すると、
  現在のステータス・期限日にもとづいて必ず色が再計算されます（手動で塗った色は
  上書きされます）。

## 毎朝自動で期限チェックを走らせたい場合（時間主導型トリガーの設定）

手動でクリックしなくても、毎朝自動的に「期限チェック実行」を走らせることができます。
（自動送信されるのは色分けの更新のみで、メール送信などは行いません。
毎朝スプレッドシートを開いて確認する運用を想定しています。）

1. スプレッドシート上部メニューの「拡張機能」→「Apps Script」を開く
2. 画面左側の時計マークのアイコン（「トリガー」）をクリックする
   【画面：Apps Scriptエディタの左メニューでトリガーアイコンが見えている状態】
3. 右下の「＋ トリガーを追加」ボタンをクリックする
   【画面：「トリガーを追加」ボタンが表示された状態】
4. 以下のとおり設定する
   - 実行する関数を選択：`checkDeadlines`
   - 実行するデプロイを選択：`Head`
   - イベントのソースを選択：`時間主導型`
   - 時間ベースのトリガーのタイプを選択：`日付ベースのタイマー`
   - 時刻を選択：`午前7時〜8時`（好きな時間帯を選択）
   【画面：トリガー設定フォームに上記内容を入力した状態】
5. 「保存」をクリックする
6. 初回のみ権限確認画面が出るので、初回セットアップ時と同様に許可する
7. 画面に戻り、一覧に `checkDeadlines` のトリガーが追加されていることを確認する
   【画面：トリガー一覧に checkDeadlines が表示された状態】

これで毎朝自動的に案件一覧が色分けされ、出社してスプレッドシートを開くだけで
期限超過・期限間近の案件がひと目で分かるようになります。

トリガーを停止したい場合は、同じトリガー画面で該当行の右側にある
「⋮」（点3つ）メニューから「トリガーを削除」を選んでください。

## シート構成の一覧

| シート名 | 内容 |
|---|---|
| 顧客マスタ | 顧客ID／会社名／担当者名／連絡先 |
| 案件一覧 | 案件ID／顧客ID／案件名／案件種別／担当者／受任日／期限日／ステータス／進捗メモ |
| ダッシュボード | 「③ ダッシュボード更新」で自動生成される集計結果（手入力不要） |
| 設定 | 「期限間近日数」（初期値7日）を変更できる |
| エラー一覧 | 「② 期限チェック実行」「③ ダッシュボード更新」で検出した入力不備の記録（自動生成） |

## 注意事項

- 本ツールは外部のAPIやサービスとは一切通信しません。すべてお使いのGoogleアカウント内
  （スプレッドシートとApps Script）だけで完結します。
- メール送信機能は搭載していません（毎朝の自動チェックも、色分けの更新のみです）。
- 顧客情報などの実データを扱う際は、共有設定（閲覧・編集権限）を必要な人だけに
  絞ることを推奨します。
